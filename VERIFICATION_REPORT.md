# Full-Stack URL Shortener Application — Clean Emerald & White Theme Edition

## Clean Light & Dark Theme System
The Light Theme has been reverted to the pristine **Supabase Emerald & White** aesthetic:
- ☀️ **Light Theme ("White Theme")**: Pristine white background (`#f8fafc`), double-bezel concentric cards, emerald gradient buttons (`from-emerald-500 via-teal-400 to-emerald-500`), emerald badges (`bg-emerald-500/10 text-emerald-700`), and emerald links.
- 🌙 **Dark Theme**: OLED dark palette (`#040507`), glass panels (`#090a0d`), and emerald radial mesh glow.
- 🖥️ **System Preference**: Automatic detection & synchronization with the operating system's theme preference.
